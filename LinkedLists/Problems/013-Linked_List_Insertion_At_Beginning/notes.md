# Problem
You are given the head of a Singly Linked List and a value x, insert that value x at the beginning of the LinkedList and return the head of the modified Linked List.

# Test Case
Input: list = [2,10], x = 1
Output: [1,2,10]

# Pattern
- Node Insertion and Creation

# Algorithm
- Start
- Create a dummy node with value x
- Insert the dummy node before head
- Return the dummy node
- End
