# Problem
Given head of a singly linked list. Find the length of the linked list, where length is defined as the number of nodes in the linked list.

# Test Case
Input: list = [1,2,3,4,5]
Output: 5

# Pattern
- List Traversal

# Algorithm
- Start
- Initialise an integer count
- While head is not null, increment count and move head
- Return count
- End
